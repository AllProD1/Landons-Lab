# Troubleshooting Log

Record symptoms, evidence, root cause (if known), fix, and verification. The entries below summarize historical incidents and should not be interpreted as proof that the issue is still present.

```markdown
## YYYY-MM-DD — Short symptom

**Impact:**
**Symptoms:**
**Evidence / commands:**
**Root cause:** Unknown / confirmed
**Resolution:**
**Verification:**
**Prevention / follow-up:**
```
